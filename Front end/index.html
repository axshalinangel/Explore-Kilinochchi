💡 Traveler Guidelines & Tips for Kilinochchi

  • Modest Dress Code: Cover shoulders and knees when entering Murukandy Kovil, Kandasamy Kovil, or Lumbini Viharaya. Footwear must be removed before entering sanctum grounds.
  • Cash Currency: Carry local currency (LKR) in small denominations for public markets, parking, and traditional food stalls.
  • Photography: Photography is welcomed at war memorials and scenic points; please ask vendor permission at the Public Market.
  • Sun Protection: Northern sunshine is intense between 11:30 AM and 3:30 PM. Carry bottled drinking water, sunglasses, and sun protection.

About Explore Kilinochchi

This web-based tourist information and trip planning system addresses the fragmentation of local tourism information across northern Sri Lanka. By centralizing 12 selected destinations under structured categories, measuring verified distances from the student reference location (< 25 km radius), and offering an automated one-day itinerary engine, the application simplifies travel planning for both domestic and international visitors.

Project Aim

To develop a user-friendly web application that enables visitors to discover selected attractions in Kilinochchi and efficiently plan their visits using organized location-based information.

Architecture Stack

C# ASP.NET Core Web API backend, MySQL relational database with Entity Framework Core, and responsive vanilla HTML5, CSS3, and JavaScript frontend.
